## 💡 经验教训

### 1. 任何静态 `import monaco-editor` 都会破坏懒加载
**只要存在一处顶层静态导入，整个 chunk 拆分即失效。**

- 问题：类型导入与运行时导入边界混淆，导致 Monaco 被打回主 bundle
- 应对：运行时用 `getMonaco()` / `getMonacoSync()`，类型用 `import type`

### 2. `formatChanges` 与 `formatSelection` 一字之差
**epi2-03 初版使用 `editor.action.formatChanges`，导致范围格式化完全失效。**

- 影响：格式化作用于错误范围，功能静默失效
- 修复：改用 `formatSelection`（通过 code review patch 发现并修复）

### 3. 闭包过期问题反复出现
**`isFormatting` 用 state 而非 ref，闭包捕获了过期值。**

- 影响：格式化的 pending 状态无法正确复位
- 修复：state → ref，并在代码审查中被捕获
