## 💡 经验教训

### 1. React Compiler 不处理自定义 Hook 的公共 API
**`compilationMode: 'infer'` 不会稳定自定义 Hook 返回函数的引用。**

- 问题：epi1-03 中一度将 5 个自定义 Hook 的 `useCallback` 一并移除，导致依赖方 effect 反复触发
- 影响：潜在无限循环 / 性能抖动
- 解决方案：自定义 Hook 对外暴露的函数仍需 `useCallback`（Compiler 只在组件体内做 memoization）

### 2. `infer` 模式与手动 memo 存在冲突期
**编译器的推断式优化与 159 处既有手动 memo 并存，语义与性能收益不透明。**

- 影响：无法确定哪些手动 memo 已被编译器覆盖
- 应对：epi1-02 仅验证配置而非真实行为，将清理推迟到 epi1-03 专项处理
