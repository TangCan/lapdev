- (constraint) 继承父级 architecture-lapdev-2026-09-28 的 modular monolith、AD-1 capability entry points、AD-2 backend state ownership、AD-3 versioned event envelope、AD-5 LSP Manager、AD-6 application/deployment authorization layers、AD-7 adapter state boundary，子 Spine 不得削弱或重编号。
- (direction) Fast path：只产出 build-substrate architecture spine，不产出额外方案说明、C4 图集或团队视图。
- (decision) 远程认证统一在 transport adapter 进入 application service 前解析为 AuthenticatedCapabilityContext；认证、会话、workspace 和 capability policy 的绑定由后端维护，防止 HTTP 与 WebSocket 各自授权。
- (decision) workspace isolation 使用后端 WorkspaceBoundary service 作为唯一边界判定点；所有文件、Agent、Git、终端、LSP 和 AI adapter 只能接收规范化且已授权的 workspace handle，防止路径和租户标识在 adapter 中漂移。
- (decision) remote policy profile 默认 deny，capability、working directory、environment、network target、resource limit 和 interactive mode 均需显式允许；local-trusted profile 不得被 remote-shared profile 隐式继承。
- (decision) 终端和子进程通过 CommandPolicy service 先解析可执行文件、参数、环境和 cwd，再交给 bounded process adapter；shell 组合、危险命令、越界 cwd 和未允许环境变量必须在应用边界拒绝并审计。
- (decision) AI secret policy 将凭据保留在服务端或部署注入边界；remote client 只获得不可逆的配置状态，日志、事件、审计和错误不得携带 key 或完整 prompt。
- (decision) 部署 permission profile 由启动配置选择并在启动时自检；entrypoint、Deno permissions、container filesystem/network/env/process permissions 和 health check 必须作为同一 profile 验证。
- (decision) 审计事件统一复用父级 event envelope 的 type/version/workspaceId/sessionId/requestId/revision，并只记录决策摘要、correlation data、结果和脱敏原因。
- (assumption) 第一版 remote-shared 目标是受控远程共享，不实现公网多租户身份提供商、组织目录或跨租户协作。
- (question) 具体认证 provider、token/session lifecycle、撤销和密钥轮换由产品/部署决策确定后再绑定 adapter。
- (question) 共享 workspace 成员模型和 tenant/project hierarchy 暂不在本 spine 内决定，必须在进入公网多租户前补充。
- (question) 允许的命令、网络目标和资源额度需要按部署环境形成 policy catalog；本 spine 只固定默认拒绝和集中判定。
- (event) architecture spine finalized in Fast path scope: inherited platform invariants retained and remote security/deployment divergence points recorded.
- (decision) 认证机制确定为受控远程共享 v1 的部署注入访问令牌：服务启动从 LAPDEV_REMOTE_ACCESS_TOKEN 读取一次性 bootstrap secret，成功认证后换取服务端内存中的 opaque session；不引入外部 IdP，不把 token 放入 URL、localStorage 或日志。
- (decision) 浏览器 session cookie 使用 Secure、HttpOnly、SameSite=Lax、Path=/ 和短生命周期；WebSocket 只接受已解析并绑定 principal/workspace/session 的服务端 session，Origin 只作辅助检查。
- (decision) workspace 隔离 v1 采用单部署单 workspace root、单 remote session 绑定一个 workspace；不支持共享 workspace 成员、跨 workspace 切换或公网多租户。
- (decision) remote-shared-v1 默认允许 workspace 内文件和 Agent 能力、只读 Git adapter 和配置好的 LSP adapter；任意终端 shell 默认关闭，必须通过显式 deployment policy 才能开启。
- (decision) 命令策略 v1 不接受 shell 字符串；Git 只允许显式只读子命令集合，LSP 只允许配置文件中的固定可执行文件和 workspace root，所有 cwd、参数、环境和资源限制集中由 CommandPolicy 判定。
- (decision) AI secret v1 由部署环境注入并仅在后端 provider adapter 内使用；不实现外部 secret store，远程客户端只获得已配置/未配置状态，密钥轮换通过重新部署完成。
- (decision) remote-shared-v1 permission profile 显式收窄 Deno/container 文件、网络、环境和进程权限；默认不授予任意 shell，allow-run 只包含固定 Git/LSP 可执行文件，发布门禁验证允许路径和拒绝路径。
- (decision) session store v1 使用后端内存并在进程重启后全部失效；生产部署必须提供 HTTPS/TLS 终止，测试环境可使用明确标记的本地例外。
- (event) security decisions resolved for remote-shared-v1: controlled single-workspace deployment, bootstrap token to opaque session, deny-by-default command policy, server-side environment secrets and explicit permission profile.
