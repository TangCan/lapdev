# 决策与研究范围

决定 npm 注册受阻时 Lapdev 的替代分发方式。延续已有 GitHub Release 平台运行时，不使用镜像。用户请求授权本次原地调研；不实施发布流程变更、不发布版本。

硬约束：不要求发布者拥有 npm 账号；公开用户无需领取包仓库 token；支持当前 Linux x64、macOS arm64 运行时；版本可固定、可校验、可回退。

比较：直接 Release 压缩包、用户级安装脚本、Release 托管 npm tarball、Homebrew 自建 tap；筛除增加用户凭据负担的替代注册表。

偏好权重（分析假设）：复用程度 35%、用户安装体验 30%、维护成本 20%、无 Node 依赖 15%。0–5 分是工程判断，不是外部测量。

技术研究 / select；沿用 standard 来源与深度上限，normal 校验。无子代理工具，主代理顺序归纳；独立网络查询批量执行。预计数分钟。以前报告用于需求背景，新来源单独建档，不作为本次外部证据。日期 2026-09-30。
