- (decision) 批准技术型选择研究：比较单体 npm、npm CLI + GitHub Release、optional packages、纯 Release 四种方案；采用广度优先、标准深度、正常验证，输出可执行迁移计划。
- (source) Round 1 source batch: official DeepSeek Harness repository; official Deno compile/deploy documentation; official npm package.json/trusted publishing documentation; official GitHub Releases documentation.
- (claim) ref=[1] status=verified class=pattern pub=2026-09 — DeepSeek Harness documents npx @deepseek-ai/dsh web as its quick-start path and also supports source installation.
- (claim) ref=[2] status=verified class=compatibility pub=2026-09 — Deno compile produces standalone executables and documents cross-compilation for Linux, macOS, and Windows targets.
- (claim) ref=[4] status=verified class=integration pub=2026-09 — npm package.json supports bin, files, and optionalDependencies fields relevant to a CLI and platform runtime packaging.
- (claim) ref=[5] status=verified class=security pub=2026-09 — npm Trusted Publishing uses GitHub Actions OIDC and can generate provenance for public packages.
- (claim) ref=[6] status=verified class=integration pub=2026-09 — GitHub Releases are tag-based and support downloadable release assets with stable latest/asset links.
- (source) Round 2 source batch: official Deno FFI/compile/permissions documentation; official Rust Cargo target documentation; official npm package metadata documentation; official GitHub Release documentation.
- (claim) ref=[7] status=verified class=compatibility pub=2026-09 — Deno FFI dynamic libraries require real filesystem handling and explicit inclusion when compiling standalone binaries.
- (claim) ref=[8] status=verified class=implementation pub=2026-09 — Deno compile has limitations for dynamic imports and requires explicit inclusion of assets not statically reachable.
- (claim) ref=[9] status=verified class=compatibility pub=2026-09 — Cargo supports explicit target triples and target-specific builds.
- (decision) 研究中期决策：推荐 npm CLI + GitHub Release 平台运行时，而不是单体 npm 包；Deno 可编译为平台启动器，但 Rust FFI 库必须作为显式真实文件随平台运行时分发。
- (event) 研究完成：推荐 npm CLI + GitHub Release 平台运行时；建议先实现 Linux x64 与 macOS arm64 垂直闭环，再扩展平台。最早复核日期 2026-10-29。
