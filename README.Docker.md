# Docker 历史资料

旧 Docker Compose 部署已停止支持。当前安装请使用 [GitHub Release CLI 和平台运行时](docs/release-installation.md)。

原配置保存在 [历史 Compose](docs/legacy/docker-compose.yml)，原镜像说明保存在 [历史 Docker 资料](docs/legacy/README.Docker.md)。这些资料不代表当前受支持的部署入口；归档配置中的相对路径保留原样。

Dockerfile、运行时 entrypoint 和构建依赖保留。此次调整不会停止或删除已有容器、卷或工作区数据。
