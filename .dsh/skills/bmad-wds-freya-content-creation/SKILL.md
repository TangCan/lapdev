# Freya's Content Creation Guide

**Original source:** `_bmad/wds/data/agent-guides/freya/content-creation.md`

**When to load:** Before creating strategic content (headlines, features, text sections)

## Core Principle

**Content is strategic, not decorative.** Every word should trigger user psychology and serve business goals.

## Content Creation Workshop — When to Use

✅ Headlines and subheadlines, Hero sections, Feature descriptions, CTAs, Page sections

❌ Field labels, Button text, Error messages, UI microcopy (that's Tone of Voice)

## Quick Mode vs Workshop Mode

### Quick Mode
**When:** Simple content, experienced user, crystal clear context, tight time.

Process: Load Trigger Map → Consider Customer Awareness → Apply Golden Circle → Generate options → Explain rationale.

### Workshop Mode (6-Model Framework)
1. **Content Purpose** — "What job does this content do?" (specific and measurable)
2. **Trigger Map** — Business Goal, User, Driving Forces, Solution
3. **Customer Awareness Cycle** — Where user is → Where we want them
4. **Action Mapping** — "What action does this enable?" Strip fluff, focus on actions
5. **Badass Users** — Frame content around user becoming capable. Show transformation, reduce cognitive load
6. **Golden Circle** — Structure: WHY → HOW → WHAT

## Content Purpose Examples

✅ Good: "Convince Problem Aware users that proposal speed matters more than perfection"
❌ Bad: "Make users want the product"

**Test:** Can someone else determine if the content succeeded?

## Tone of Voice vs Strategic Content

| Tone of Voice (Product-Wide) | Strategic Content (Context-Specific) |
|------------------------------|--------------------------------------|
| Field labels: "Email address" | Headlines: "Stop losing clients" |
| Button text: "Get started" | Value props: "AI-powered templates" |
| Error messages | Feature benefits |
| **Defined once** in Product Brief | **Created with workshop**, varies by context |

## Quick Reference

Before creating any strategic content:
1. Define purpose
2. Load Trigger Map
3. Check awareness
4. Apply Golden Circle
5. Filter with Action Mapping
6. Frame as empowering
7. Validate purpose
